Greedy Room Allocation (Interval Partitioning)

Partitions concurrent interview requests into the minimum theoretical number of physical rooms using a Min-Heap.

← Back to Portal

⚡ Algorithm Principles:

1. Sort all schedules by start time. 2. Use a Min-Heap to track the earliest room completion time. 3. If earliest room free time ≤ current interview start, reuse the room; otherwise, allocate a new room track.

Time Complexity: O(n log n)
Space Complexity: O(d) rooms
Interview Requests Input
Interview ID / Role Start Time End Time Action
Real Project Integration: When an Admin initiates automatic room scheduling for a drive with 50+ candidates, the Greedy Room Allocator packages all interviews into the minimum required physical labs/cabins without idle space wastage.
