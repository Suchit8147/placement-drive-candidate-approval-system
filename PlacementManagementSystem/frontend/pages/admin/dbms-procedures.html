🔄 Automated Database Trigger Architecture:

1. User invokes backend API ➔ 2. Backend executes MySQL Stored Procedure sp_update_application_status ➔ 3. Procedure updates record in Applications table ➔ 4. MySQL database engine automatically fires AFTER UPDATE trigger trg_application_status_notification ➔ 5. Trigger executes internal join query and inserts a persistent alert into Notifications table without application-layer code!
